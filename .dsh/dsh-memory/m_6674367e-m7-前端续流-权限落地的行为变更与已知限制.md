M7 前端（分支 feat/m7-frontend-contract）确定的行为变更，后续开发不得回退：
1) 断线重连改为「续流优先」（GET /runs/{id}/stream?after_seq=），不再重发 POST /chat/stream，因此不会新建 run；400 replay_too_large / 404 / 连接失败才回退轮询。
2) 写操作按 auth.isAdmin 渲染入口，普通用户直接看不到写入口，后端统一返回 403 forbidden（details.required_role=admin）。
3) 登录/注册的 401 不走 token refresh，直接显示后端文案（如「邮箱或密码错误」），不再显示「登录已过期」。
4) 降级轮询后 run 未终态时，恢复横幅只提供「刷新状态」，不再提供「重试发送」。

已知限制（有意留作后续增强）：
- 回放 run.started 会清空 process；若回放中途失败，已清空卡片需等终态刷新。
- 收到 error 终态事件后曾误触发重连，已修复并加回归测试，勿再引入同类判断。
- E2E 仍只跑 mock 构建，Playwright 未覆盖断线续流；真实增量 delta 续流与多实例续流未取证（后端单实例、LLM key 为占位，run 以 llm_error 结束，但事件落库可验证回放/终态关闭/去重）。
