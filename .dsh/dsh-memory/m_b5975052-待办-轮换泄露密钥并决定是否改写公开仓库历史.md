1) 轮换 4 把已在会话日志中明文落盘的 Key（不记录具体值）：后端项目 `.env` 里的 `LLM_API_KEY`（DeepSeek 平台）；`~/.dsh/credentials.yaml` 里的 `DEEPSEEK_API_KEY`、`ZAI_CODING_CN_API_KEY`（智谱开放平台）、`XIAOMI_API_KEY`（小米开放平台）。按“已暴露”处理——即便 push 被拦，值仍明文存在本地会话日志里，且排查过程中有一把 Key 被完整打印进工具输出。

2) 决定是否清理公共历史：`git filter-repo --path .dsh/sessions --invert-paths` 后 `git push --force origin master`，会改写公共历史（已 clone 者冲突、GitHub 旧 blob 可能缓存一段时间）；不做也不影响 push。

3) 可选防复发：加本地 pre-commit 钩子，命中 `.dsh/sessions` 或疑似密钥模式即拒绝提交；本地钩子不进仓库、幂等，若要换机/团队生效可做成 `pnpm prepare` 自动安装。
