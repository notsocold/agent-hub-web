2026-11-12 完成 agent-hub-web 像素级对齐（阶段 2），本地提交 29e5707（未推送；推送与合并由用户自行操作）。

差距本质：颜色 token（paper/surface/ink/prussian/amber）本就与原型一致，差距集中在布局骨架、组件结构、字号/间距/层级与交互形态，属于「按原型重做呈现层」，不是调间距。业务逻辑、接口契约、RBAC、续流、审批状态机一行未改。

新增基座：src/styles/prototype.css（v7 工作台与页面原型 CSS 整体移植为全局类 .page-head/.stats/.toolbar/.st/.btn/.panel/.data-table/.chat-*/.agent-card/.doc-row/.wf-card/.settings-nav 等）；src/styles/admin.css（v8 管理台样式统一加 .admin-shell 前缀，避免覆盖业务页同名类）；IconSprite.vue + AppIcon.vue（55 个原型图标替换手写 SVG）。AppLayout/SideNav/AccountMenu/PageShell/PageHeader/StatCard 按原型重做；对话页改动最大（chat-head、运行条、节点时间轴、思考/技能/检索/工具/MCP/A2A/审批卡、composer、右栏运行轨迹）。

有意保留的差异（不要当 bug 修）：
1) 后端无契约的展示一律省略或降级、不造假数据：工作流「运行次数」、管理概览「近 7 天运行量柱状图」、用户页「会话数」列、审计「IP/结果」、角色矩阵细粒度权限。
2) 管理台入口按原型收进账号菜单（v7 侧栏不出现管理员入口）。
3) 对比度取舍：侧栏底为 paper-2，原型 --ink-3(#606b72) 仅 4.37:1，侧栏内改用同色系 #5a656c(4.7:1)，页面主体仍用原型值；归档会话由整行 opacity 改为文字色降级。
4) Element Plus 弹层外壳（任务详情、注册、上传、改密、命令面板）暂保留，仅主体视觉对齐；原型装饰项（演示徽标、铃铛、邀请用户）未实现。
5) 保留的功能增强：多审批卡/倒计时、两段式注册、详情抽屉、任务轮询深链、虚拟滚动、⌘K、诊断抽屉、暗色主题、移动端搜索入口。

因结构变化同步调整了若干单测与 4 个 E2E 的定位方式（状态胶囊改 .chat-actions .status-chip、管理台入口走账号菜单、抽屉态断言 .app.sidebar-open），未删任何校验断言。
