基线：v7/v7-pages/v8 原型；后端 agent-hub 仍 M0（接口均为设计稿）。

关键结论：
- 聊天流必须在开始时给出 `run_id`（`X-Run-ID` 或 `run.started`），否则停止按钮无法工作。
- HITL 期间 SSE 生命周期未定义（D8）；建议保持连接 + 15 分钟超时，否则补续流端点。
- 附件上传是独立资源，不能复用知识库上传；生成产物复用 attachments（purpose=artifact）。
- 智能体需要 `POST /agents/preview`、健康四态（加 degraded）、软删除；任务需要 8 态与 resume/authorize/reject；`authorize` 是新增用户级授权能力，现有 A2A 设计只通知管理员。
- 知识库归属 D7 未定：全局（管理员写）或加 owner_user_id；若加 owner，checksum 唯一约束要按 owner 拆分。
- 工作流 D1 未定：建议轻量步骤模板（非 BPMN），且需先补后端 ADR；MVP 可只做模板/发布/对话选择/轨迹，版本与导入导出后置。
- v8 管理端不一次做完：M5.0 概览/审计/用户只读/已有系统设置；M5.1 RBAC；M5.2 菜单/字典。
- 后端现有 `409 conflict` 需要被新具体错误码细化；需同步更新 agent-hub `docs/api.md`。

校验：62 个 JSON 代码块、19 条 SSE data 行均可解析；交接包内 0 个断链；已按两名 reviewer 的发现修正 MCP 工具名、a2a agent 类型、run_events/a2a_task_events 表、幂等键、权限键命名空间等。

注意：D1–D8 仍待用户/后端拍板，交接包按推荐项标注，不代表已定。
