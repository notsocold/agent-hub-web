用户质疑「界面和原型设计不一样」。定论：差异分两类。

A. 呈现型差异（本轮就该做好，属于实现欠账）：
- 全局布局：原型 v7 是 288px 单侧栏（一级导航+会话列表+账号）+ 对话区 + 332px 常驻运行详情；当前实现是 288px 导航栏 + 272px 二级会话栏 + 对话区 + 抽屉。
- 运行详情：原型为常驻可折叠右侧面板（概览/事件/筛选/智能体），当前是简化抽屉。
- 对话时间线：结构与卡片已有，但样式、信息密度、间距明显简化。
- 输入栏缺附件 chip；另新增了原型没有的欢迎页+建议问题（需用户确认是否保留）。
- 工作流/智能体/任务/知识库/设置：当前仅为 Element Plus 表格+统计卡骨架。

B. 功能型差异（计划内，点击提示「后续接入」不做假成功）：附件上传、技能/MCP/知识库选择、@ 文件、智能体注册预览与启停、任务补充信息/授权/拒绝、知识库上传与检索调试、工作流编辑器、管理端。

原因复盘：把「按企业生产环境通用做法」理解成功能闭环优先（通用件交 Element Plus、仅对话时间线自研），未做视觉收口；本机无浏览器无法截图对照，只做了构建/类型/单测验证；未把「视觉还原」列为独立验收项。

建议工作包：P0 全局壳+对话工作台布局（合并单侧栏、≥1180px 恢复右侧常驻运行详情、窄屏才用抽屉）→ P1 组件视觉精修（tokens/状态色/间距/暗色）→ P2 业务页面形态升级为原型形态 → P3 功能按 M1.5→M2→M4→M5+ 接入。改动集中在 AppLayout.vue、SideNav.vue、ChatView.vue 与 components/chat/ 卡片样式，基准为 docs/prototypes/ui-v7.html。

待用户拍板：范围选 A（仅 P0+P1）/ B（P0+P1+P2）/ C（先不动视觉）；以及是否允许安装 Playwright+Chromium 做截图自检。确认前不改代码。
