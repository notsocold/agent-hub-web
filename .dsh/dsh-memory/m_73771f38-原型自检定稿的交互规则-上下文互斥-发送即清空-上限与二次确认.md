agent-hub-web 原型定稿的交互规则：
- 上下文选择互斥；
- 发送后输入框清空；
- 技能 / MCP 有数量上限；
- 不再保留独立停止按钮：停止按钮与发送按钮同一位置、同尺寸，本轮运行中（包括“待审批”状态）主按钮切换为红色实心方块停止按钮，aria-label/title 为「停止本轮运行」；点击后取消本轮并同步刷新顶部状态、侧栏会话状态、运行轨迹、操作轨道与审批卡状态；本轮结束/已取消后恢复为发送按钮（无内容时禁用）；待审批时审批卡上的「批准 / 拒绝」仍可用；
- 危险操作需二次确认。
