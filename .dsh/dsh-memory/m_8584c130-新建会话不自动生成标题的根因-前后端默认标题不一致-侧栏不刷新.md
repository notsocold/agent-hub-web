协议：agent-hub-web 点「新建会话」会先用默认标题预创建会话，后端（app/modules/chat/service.py）只在标题等于其默认值时用首条消息生成标题。

根因：前端默认标题为「新会话」而后端只认「新对话」，两边不一致导致标题永远停在「新会话」；原先叠加 refreshHistory 不回写侧栏 store 的问题。

修复口径（本次）：
- 前端 src/api/conversations.ts 默认标题改为「新对话」，mock/routers.ts、mock/db.ts、mock/stream.ts 兜底标题同步。
- 后端 service.py 条件改为 `is_new or title in {"新对话", "新会话"}`：既兼容库里旧数据，又不会覆盖用户手动改名的标题。
- 验证：用 dev 账号走真实 API 创建旧默认标题会话 → 发首条消息 → 标题自动生成，验证后清理。

遗留：库中仍有标题为「新会话」的历史会话，会在下次对话时被自动修正。
