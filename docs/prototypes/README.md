# 原型索引

本目录保存 Agent Hub 前端的单文件 HTML 原型。原型用于评审信息架构、交互与视觉，不是可运行的产品代码；`src/` 仍处于 M0 结构初始化。

## 1. 入口

| 文件 | 内容 | 建议入口 |
|---|---|---|
| [`ui-v7.html`](ui-v7.html) | 对话工作台：会话侧栏、过程时间线、审批、运行轨迹、Agent 抽屉、输入栏「+」菜单 | 先打开这一页 |
| [`ui-v7-pages.html`](ui-v7-pages.html) | 工作流 / 智能体 / 任务 / 知识库 / 设置（含“个人能力”四区块） | 从工作台侧栏进入 |
| [`ui-v8-admin.html`](ui-v8-admin.html) | 管理控制台：概览、用户、角色权限、菜单、字典、审计、系统设置 | 独立入口；`ui-v7.html` 不出现管理员入口 |

历史版本 `ui-v1`–`ui-v6` 保留用于追溯，不再迭代；新改动只进 v7/v8 或下一个版本文件。

## 3. 与后端契约的关系

已对齐的部分：

- 对话 SSE、工具/技能/MCP/审批事件、运行轨迹、会话 CRUD；
- 智能体注册/健康检查/启停、任务状态与取消、知识库检索；
- M1.5 的指令、记忆、技能、MCP 设置接口。

仍需后端补契约的部分：

- 工作流管理（当前是前端概念，后端没有表/API，且架构明确不做通用 BPMN 编排器）；
- 管理控制台的用户、角色权限、菜单、字典、审计查询（目前只有 `users.role` 与 `audit_logs` 表，没有对应 API）；
- `chat/stream` 的 `model` / `reasoning_effort` 字段与 reasoning 事件；
- 附件上传端点、知识库选择字段、会话搜索 `q` 与 `message_count`；
- 审批列表 `GET /approvals` 的页面入口。

详细对照与优先级见自检报告第 3–4 节；面向后端的字段级契约、工作包与 fixtures 见[后端交接包](../handoff/README.md)。

## 4. 使用方式

直接用浏览器打开 HTML 即可，无需构建或启动服务。部分浏览器在 `file://` 下会限制 `localStorage`，主题切换仍可用，但刷新后可能不保留。

原型中的写操作大多用 toast 或本地 DOM 更新模拟；标注“原型演示”的按钮不会调用真实接口。A2A 数据、智能体、任务、知识库均为演示数据。

## 5. 迭代约定

- 单文件、离线可用、无 npm 依赖、图标内联；
- 新版本复制为 `ui-vN.html` / `ui-vN-pages.html`，不覆盖历史版本；
- 改动后至少做：标签配对、重复 id、内部锚点、`node --check`、DOM 引用、CSS 变量检查；
- 设计变更同步更新本目录与 `docs/pages.md`，契约变化同步到自检报告。
