## 2. M1.5 字段差异与前端处理

| 资源 | 草稿/前端旧假设 | 后端实际 | 前端处理 |
|---|---|---|---|
| 指令保存 | `PUT {value}` | `PUT {content}` | `src/api/instructions.ts` 发 `content`；mock 兼容 `value` |
| 技能列表 | `{items,next_cursor,has_more}` | `{items,stats}`（不分页） | `skillsApi.list` 返回 `SkillListResult`，不再消费 cursor |
| 技能创建 | 可选 slug | `{name,description,content}`，description 必填 | `SkillCreateRequest` 收紧；设置页去掉 slug 输入 |
| 技能导入 | `{skill,warnings}` | 直接返回技能 + `imported/ignored` | `skillsApi.importZip` 归一化为 `{skill,warnings}` |
| 技能可编辑 | `editable` | 不返回，按 `scope` 推导 | `normalizeSkill`：`editable = editable ?? scope==='user'` |
| 技能目录 | `enabled` | `effective_enabled` | `skillsApi.catalog` 映射为 `enabled` |
| 记忆导出 | `{exported_at,memories}` | `{version,exported_at,items}` | `memoriesApi.exportAll` 映射为 `memories` |
| MCP 列表 | 分页 | `{items,stats}` | `mcpApi.listServers` 返回 `{items,stats}` |
| MCP 可用目录 | `{servers,tools}` | `{items}`（只有服务器） | `mcpApi.available` 归一化 servers；工具在展开服务器时调用 `/mcp/servers/{id}/tools` 懒加载（`capabilities` store） |
| MCP 检查结果 | `{health_status,latency_ms,tool_count,checked_at,error}` | `{id,health_status,latency_ms,message,tools_discovered,last_checked_at}` | `normalizeCheck` 统一为前端字段 |
| MCP 凭据 | `auth_hint` | `credentials_hint` | `normalizeServer` 映射；提交用 `headers`（`Authorization` 推荐 `env:NAME`，值原样发送） |
| MCP 创建 | `{name,url,auth,auto_inject}` | `{name,slug,url,transport,headers,...}` | 设置页补 slug（按名称生成）、发 headers；auto_inject 创建后通过 PATCH 修改 |
| 附件 | 状态 `processing/ready/failed` | 另有 `deleted`；checksum 无前缀 | 类型补 `deleted`；不展示 checksum |
| 技能启停字段 | `enabled` | `effective_enabled` 为准 | `normalizeSkill` 用 `effective_enabled` 覆盖 `enabled` |

## 3. M2 字段差异（实测）

- Agents / Tasks 响应字段与前端 `src/types/agent.ts`、`src/types/task.ts` 基本一致；后端 schemas 显式按前端类型编写。
- 任务列表 `state` 只接受重复参数（`state=completed&state=working`），不接受逗号分隔；前端目前单选，不传逗号。
- `POST /tasks/{id}/resume` 返回 `{task, run}`；`cancel`/`authorize`/`reject` 直接返回任务详情。
- `system/info.capabilities.agents/tasks` 在 M2 落地后为 `true`。
- 对话调用远程 Agent 的 SSE 序列实测为：
  `tool.start(source=a2a)` → `a2a.task(submitted)` → `a2a.task(working)` → `a2a.artifact` → `a2a.task(completed)` → `tool.result(source=a2a)` → `message.delta` → `message.done`。
- `a2a.input_required` / `a2a.auth_required` 期间 SSE 保持打开；任务页 `resume` / `authorize` / `reject` 后同一流继续并最终 `message.done`。

## 5. 已知限制

- 技能语义检索、记忆语义检索仍为 M4；当前 `q` 走 ILIKE。
- MCP 每次调用重建连接（未做连接缓存）；stdio 仅管理员。
- 审批/A2A 等待基于进程内 registry，单实例前提（多实例需 M6 总线）。
- 审批超时后 run 仍占锁，前端需 `POST /runs/{id}/cancel` 解锁（已由 `RunRecoveryBanner` 提示）。
